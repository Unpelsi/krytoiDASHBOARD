Помести сюда server.jar чтобы запустить реальный Minecraft сервер.

Скачать ядра:
- Paper (рекомендуется): https://papermc.io/downloads/paper
- Vanilla: https://www.minecraft.net/en-us/download/server
- Fabric: https://fabricmc.net/use/server/

Пример:
1. Скачай paper-1.20.4-xxx.jar
2. Переименуй в server.jar
3. Положи в эту папку (mc-server/)
4. Нажми "Запустить" в дашборде

Первый запуск создаст eula.txt - открой его и поставь eula=true
Также можешь отредактировать server.properties через дашборд.
